# MiniMax H3 プロンプト規則 — 変換器の知識パック

`tools/h3_prompt_convert.py` がこのファイルを読み、ローカル LLM への system prompt に組み込む。
**知見が増えたらこのファイルを編集する。Python 側は触らなくてよい。**

出典は `docs/minimax-h3-video-concat.html` の §8c ノウハウ台帳（192 行）。
確度は `実測`（この PC で測った）>`一次`（公式）>`一致`（複数二次情報）>`要検証`。

---

## 0. 変換器の役割分担（守ること）

**数値・格子・上限・尺の計算は Python 側が持つ。LLM は散文だけを書く。**
フレーム数・秒数・タイミングマーカーの位置・モーラ予算は、こちらが計算して渡す。
**LLM が計算した数値は採用しない。** 渡された数値をそのまま使う。

---

## 1. プロンプトは 5 層で書く `一致`

3 つの独立した情報源が一致している構造。

| 層 | 名前 | 中身 |
|---|---|---|
| 1 | 被写体の定義 | キャラ・服・環境・重要な小道具を**それぞれ別のオブジェクト**として扱う |
| 2 | 要約 | 動画の種類、総尺、絵コンテの読み順、アクションの連鎖全体 |
| 3 | retention | 参照情報をどれだけ厳密に保つか |
| 4 | 詳細記述 | アクションの全シーケンス |
| 5 | 制約と音声要件 | 守らせたい制約と、音の指定 |

**この形を外すと、キャラがシーン説明文を読み上げる。** 最頻の事故。

## 2. 出力フィールド名（公式）`一致`

| フィールド | 中身と書式 |
|---|---|
| `integrated_multimodal_description` | 被写体・設定・見えるアクション・カメラ・台詞、およびその瞬間の音。順次イベントは `[Shot 2] at 00:03.000` のタイミングマーカーで書く |
| `overall_soundscape` | クリップ全体の環境音、物理的な効果音、非言語の人間の音（呼吸・笑い）。**1〜4 文の連続した段落**。完全な無音を求めるときだけ `N/A` |
| `non_diegetic_music` | 観客だけに聞こえる音楽（= BGM）。**気分・テンポ・楽器編成**に焦点、**1〜2 文**。不要なら `None` |

**プロンプトは「各参照に役割を割り当てる行」から始まる。**
参照は**番号で明示的に紐づける**（「〈image 1〉から人物・服・環境を保つ」「〈audio 2〉は subject 3 の声色参照」）。
プロンプト内で画像・音声を参照するときは**三角括弧**を使う。

## 3. 台詞の書式 `一致`

- 発話は **`<d>[Japanese]…</d>`** でくくる。H3 はタグの**中**を演じ、**外**は動作として扱う。
  → **ト書きを読み上げなくなる。** これが「キャラがシーン説明を読み上げる」事故への根本策。
- 話者 ID **`(S1)` `(S2)`** はタグの**外**。**タグの中は言語と台詞だけ。**
- **喋り方の指定もタグの外**（「低く落ち着いた声で」など）。トーン・ペース・感情が変わる。
- **句読点がペーシングとイントネーションを導く。** 抑揚が不自然ならまず読点を打ち直す（コストゼロ）。
- **言語を明示する。** 日本語は 11 の安定サポート言語に入るが、固有名詞が別言語に化ける事故がある。
- **「1 行」は 1 クリップではなく 1 つの発話。** 1 クリップに複数置ける（タイミングマーカーで位置指定）。
- エンティティは**声を記述して初めて話者になる**。空欄なら無言で、ダイアログに追加できない。

### 台詞の尺 `要検証`（換算はこちらの計算）

英語 10 語 ≒ 3.5〜4.5 秒。日本語なら **20〜27 モーラ**（話速 **6 モーラ/秒**）、
漢字かな交じりの見た目で **12〜18 文字**。

**罠: クリップ長に対して台詞が短いと、H3 は余った時間を雑音で埋め、キャラがその雑音にリップシンクする** `一次`。
音だけ消しても口は動いたままで、後から救えない。**クリップ長は台詞の実尺から決める。**

## 4. 否定形は効かない `一次`

「no sound」「no spoken dialogue」と書いても**効かない**。
無音がほしいときは**肯定形で状態を描写する** —
「The character is silently deep in thought, lips closed for the entire clip.」

禁止語（英語本文）: `no `, `not `, `don't`, `doesn't`, `without`, `avoid`, `never`, `nothing`, `absent`.
**制約は必ず「こうである」と書く。**

## 5. retention の 4 段階 `一次`

| 設定 | 意味 | 使いどころ |
|---|---|---|
| `fully_preserved` | そのままコピーする | キャラクターシート |
| `partially_preserved` | ポーズと光は変わってよい | キャラクターシート（動きのあるカット） |
| `attribute_transfer` | 1 つの特徴だけを移す | 顔の移植 |
| `weak_reference` | スタイルだけ。一般的な似姿・種類・構図・雰囲気 | 画風の参照 |

**顔を移植するときは、受け手を「顔なし」で記述する。** そうしないとモデルが勝手に顔を描く。

## 6. 参照ファイルの使われ方 `一次`

| used as | 内容 |
|---|---|
| `reference` | 見本 — 人物、場面、スタイル |
| `storyboard` | **構図だけ**を取る。外見は含まれないので外見用のファイルが別に要る |
| `first_frame` / `last_frame` | 出来合いのフレーム。残りをモデルが生成 |
| `key_frame` | 途中に入る。**ただし精度は保証されない** |
| `continue_from` / `edit` | 動画のみ |

**すべての参照に「役割」を名前で与える。** 画像=外見/構図、動画=動き/カメラ、音声=声/音。
何を retain / transfer / change するかを書き分ける。

**参照は 1 枚のシートに集約する。枚数を増やすほど品質が落ちる。** 長辺は短辺の 2.5 倍まで。
**参照 9 枠は Location と継続アンカーに食われて実質 7 枠。超えても黙って落ちる** `一次`。

## 7. 音 `一次`

- **【確定】出力音声は常に合成される。モデルは録音を「聴く」だけ。** 渡した波形はそのまま出てこない。
  → **日本語のアクセント問題への唯一確実な答えは「最終出力の音声トラックを日本語 TTS に差し替える」。**
- そのため**台詞には必ずかな読み（yomi）を付ける** — Style-BERT-VITS2 / AivisSpeech / VOICEVOX で
  アクセントを直すのにそのまま使える。読みが揺れる語はひらがな・カタカナに開く。
- **同じサウンドスケープの記述を全クリップのプロンプトに入れる。** 入れないと継ぎ目で環境音がリセットする。
- **継ぎ目で矛盾する音の指示を書かない。**
- **BGM を切るなら `non_diegetic_music: None`。** 編集は順次にならないので、
  モデルに BGM を作らせると継ぎ目で合わない。BGM は 1 本通しで別トラックにする。
- **Global music は楽器とテンポを書く。気分や感情ではなく。**
- **音は明示的に名指しする。** 指定しないとミックスは運任せになる。
- 参照音声は**最大 3 本 / 各 2〜15 秒 / 合計 15 秒以内**。実用的な長さは 5〜10 秒。
- **リップシンクは音声を渡すだけでは同期しない。** 台詞が正しいタイムスタンプ位置に
  **プロンプトとして**置かれて初めて口が合う。波形だけでは合わない。
- **台詞は継ぎ目をまたがせない。** 継ぎ目は文と文の間、または息継ぎに置く。
- **セリフはクリップの終端 0.20〜0.24 秒前に張り付く** `実測`。ショットを伸ばして増えるのは
  発話「前」の無音。**継ぎ目のクロスフェードは語尾を削る危険がある。**
- 複数人: **まず 1 クリップ 2 人で試し、声が混ざったら切り返しに分ける。**
  公式に Issue #17「Ref2VA: 複数被写体で声のアイデンティティが混ざる」がある。

## 8. クリップ設計 `実測`

- **24fps / `length % 17 == 5` の格子**（5, 22, 39, 56 …）。指定秒数は次の格子点に切り上がる。
- **運用は 25 秒（600f = 17×35+5、ちょうど 25.000 秒）固定に決定。**
  公式仕様は 4〜15 秒だが、20 秒（481f）も 25 秒（600f）も**完走・破綻無し**で実測済み。
- **30.667 秒（736f）も完走するが、3 つの指標が同時に曲がる** —
  VRAM ピーク反転（余裕 694 MiB）、超線形指数 1.26→1.41、フレーム間の動きが単調減少（2.88→1.88）。
  **落とした理由は品質ではなく VRAM 余裕。** 32GB を借りたら真っ先に再確認する。
- **クリップは可能な限り長く取る**（継ぎ目を減らすため）。ただし台詞の実尺が上限を決める。
- **1 分 = 25 秒 × 3 本・継ぎ目 2**（独立生成でも連鎖でも）。
- 連鎖する全クリップで**アスペクト比・解像度を揃える**。
- **カット割りは技術的な劣化リセット。** 「ここは連続でなければならないか?」を継ぎ目ごとに問う。
- **1 クリップ内の複数ショットは `[Shot 2] at 00:03.000` のタイミングマーカーで指定できる。**
  台詞のあるショットは長く、動きだけのショットは短く。

## 9. 現行のベースライン `実測`

モデル `10Eros_Max_h3_TURBO-hybrid_beta4_int8_convrot` / **turbo LoRA はバイパス** /
`euler` / `simple` / **6 step** / ref2va か t2va（**i2v では使わない**）。
base に戻すなら turbo LoRA 有効 / `res_multistep` / 8 step。**混ぜると二重掛けになる。**

**4 step は使わない。** 音声 Peak が −0.1〜−1.6 dB で割れる（実用域は −7 dB 前後）。
**0.4MP だと映像は一見きれいに出るので、映像だけ見て判断すると必ず間違える。**

`prompt_optimizer` は **false**（書き換えで外見描写が足され、参照と競合する）。
FL2VA と Ref2VA の**アダプタを混ぜない**。一方の shift を他方に流用しない。

## 10. 文体（出力プロンプト本文）

- **本文は英語。台詞だけ日本語**（`<d>[Japanese]…</d>` の中）。
- 実写なら `Live-action cinematic footage` と明示。
- カメラは**動きと画角を具体的に**（`locked off on a tripod` / `slow push in from full body to a close shot`）。
- 光・グレーディング・被写界深度・`24fps` を末尾に置く。
- **形容詞を盛らない。** 動作と状態を、起きる順に書く。
